# Import de contacts dans Twenty

L’extension importe les contacts et les entreprises depuis un tableur. Les lignes sans adresse email sont enregistrées dans l’objet des contacts écartés.

La prospection, la validation Account56 et l’envoi sont gérés par le [graphe de campagne](../prospection/EXPLOITATION.md). L’objet de l’ancienne file SMTP reste déclaré pour conserver son historique lors de la mise à jour de l’extension.

Le [guide d’installation](SETUP.md) détaille le lancement local et les commandes de test. Les versions sont consignées dans le [journal des changements](CHANGELOG.md).
